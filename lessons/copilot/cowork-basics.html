A coworker with desk access — not a smarter chatbot

The difference between Cowork and regular AI chat is asking a consultant for advice over the phone vs. handing them a laptop with your files on it. Same intelligence, completely different leverage. Cowork reads and edits files in folders you connect, runs code in a sandbox, and calls connected apps — so your prompts change: you delegate outcomes, not request answers.

Your call

You want a report in your folder summarized. Which is the Cowork way to ask?

01 · Install and connect a folder

Setup

The step most people miss is connecting a folder — without it, Cowork has nothing to work on.

Setup sequence1. Confirm your tenant is in the Frontier Firm program (IT enables it) 2. Open Microsoft 365 Copilot Chat 3. Toggle on the Cowork capability when prompted 4. Connect a OneDrive/SharePoint folder — a specific working folder, not the root 5. Test: "list the files in my connected folder" 6. See your real file names? You're set up.

02 · The permission model

Stay in control

Cowork keeps you in control: some actions are automatic, some always ask first, and a couple are off-limits entirely. Set the permission you'd expect for each — then check.

Read a file in your connected folder
Run code in its Linux sandbox
Delete a file
Send an email through a connected app (Outlook)
Read your saved passwords or browser cookies

03 · Your first useful session

Do real work

The fastest way to get it: hand Cowork a real task that would take you 30+ minutes by hand. Don't start with "hello."

A strong first taskLook through my connected folder. Find documents from the last 90 days that look like meeting notes or call transcripts. For each, give me the date, a 2-sentence summary, and any action items that don't seem done yet. Present it as one markdown table I can copy.
