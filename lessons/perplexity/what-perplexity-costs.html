What Perplexity actually costs.

Perplexity prices differently from the chatbots: it thinks in searches, not tokens. Here's how the free and Pro tiers work, what the limits really mean, and how the Sonar API charges builders — honest June 2026 numbers.

01 The plans

PlanPriceWhat you get
Free$0Standard searches + a limited number of "Pro" (deep) searches per day
Pro$20/moA large daily allowance of Pro searches, Deep Research, Spaces, file uploads, the Comet browser

The key unit is the Pro search — a deeper, multi-source answer. Free gives you a handful a day; Pro gives you a generous daily cap (hundreds). You're not billed per search on Pro — you just have a high ceiling.

02 Pay-per-use: the Sonar API

For builders, Perplexity's Sonar API powers search-grounded answers in your own apps. It bills a small per-request fee (for the live search) plus per-token for the model — so it's a blend of the search model and the token model. Exact rates vary by tier; check Perplexity's current API pricing before you build.

Why Perplexity is the odd one out

Most tools charge for generating text. Perplexity also pays to search the live web every time — that's the per-request fee. That's the price of always-current, cited answers. So compare it on "cost per research task," not raw tokens.

03 What a query actually costs

  • On Pro ($20/mo): if you run, say, 10 Pro searches a workday, that's ~200/month — comfortably inside the cap, so your effective cost is just the flat $20.
  • On the Sonar API: a single grounded answer is typically a few tenths of a cent to a couple cents, depending on model and how many sources it pulls — the per-request search fee is the part chat APIs don't have.

04 Which is right for you?

  • Occasional research: Free tier — a few deep searches a day is often enough.
  • Daily research / sales / analysis: Pro ($20) — the deep-search allowance is the value.
  • Building search into a product: Sonar API — pay per request + tokens.
