One channel. One domain expert.

Every other Copilot agent is a generalist you point at things. Channel Agent is the opposite: it belongs to a single Teams channel, learns that channel's conversations and meetings, and becomes the person on the project who actually remembers what was decided in March. It is still in public preview — which changes how you should pilot it, not whether you should.

Channel Agent is in public preview and Microsoft says features are likely to change. Treat it as a pilot in one or two real channels, not a rollout. Anything you build a process around today may move.

01 What it actually does

Microsoft frames Channel Agent as a domain expert for a project, drawing on the channel's own conversations and meetings. Five capabilities carry the value:

  • Status reports. It drafts and shares them, and the team reviews, edits and customises before anything goes out.
  • Meeting integration. Meeting transcripts become knowledge sources, and it can schedule meetings with suggested titles, agendas, invite lists and times based on what the project needs.
  • Task management. It creates tasks and reminds the team about them.
  • Questions and answers. It answers in the channel, and in group chats and meetings it's invited to, using channel messages, meeting transcripts, and web search if your IT admin allows it.
  • Email. It drafts and sends email from inside Teams, which removes the Teams-to-Outlook context switch that eats status-update Fridays.

It also connects out: Microsoft documents using Channel Agent to manage tasks in Jira, Asana and GitHub, which is where it stops being a note-taker and starts being a project participant.

02 Who can use it — and who only watches

Three requirements to create, interact with and manage a Channel Agent: a Microsoft Copilot subscription assigned to you, membership of the channel where the agent was created, and permission from your IT admin to use apps in Teams.

The interesting part is what happens to everyone else, because it shapes how a channel feels once the agent is in it:

WhoCan ask the agent?Can see its output?
Channel member with a Copilot subscriptionYesYes
Channel member without a Copilot subscriptionNoYes — responses, generated content, and other people's interactions
Non-member, in a group chat or meeting the agent was added toNoYes — they see others' interactions
Why this matters for a pilot

Unlicensed teammates aren't locked out of the conversation — they see everything the agent produces, they just can't drive it. That makes a single channel a genuinely good place to demonstrate Copilot's value to people who don't have a licence yet. It also means anything the agent says is visible to the whole channel, so treat its output as public within that group.

03 Running it well

Pick a channel with real history. The agent's knowledge is the channel's messages and meeting transcripts. A channel created last week has nothing to be expert about.
Decide the web-search question first. Whether the agent can search the web is an IT admin setting. Grounded-only answers behave very differently from web-augmented ones — know which you're testing.
Use the approval step on summaries. Channel Agent's summaries can be approved or rejected. Wire that into a named person, or the first wrong status report becomes the reason leadership kills the pilot.
Add it to the project's meetings and group chats, not just the channel. Its usefulness compounds when the meeting transcripts flow back into the same brain that answers the questions.
Do configuration on desktop. Agent creation, removal and configuration must be done from desktop or web Teams. Mobile supports report approval and feedback, but not setup.
Mobile has version floors: Teams 7.11.0 or higher on iOS, and 1416/1.0.0.2025100000 or higher on Android. If a teammate says the agent “isn't there” on their phone, check the app version before you check anything else.

04 Where it beats the alternatives

You could ask Researcher to summarise a project, or build something in Copilot Studio. Channel Agent wins on a narrow but common case: the knowledge is the conversation itself. Nobody wrote the project down. It exists as six months of Teams messages and forty meeting transcripts, and every status update currently costs a human three hours of scrolling. That is the job this agent was built for.

It loses when the knowledge lives in documents rather than chat — that is SharePoint agents — or when the work is task execution rather than recall, which is Planner Agent.

Try it this week

Pick your messiest active project channel. Create the agent, then ask it the question you'd normally ask a person: “What did we decide about scope, and when?” Compare its answer to what you'd have found by scrolling. That gap is the business case.

Questions people ask

Straight answers

Is Channel Agent generally available?
No. As of August 2026 Microsoft's documentation states that Channel Agent for Teams channels is in public preview and features are likely to change. Pilot it in one or two channels rather than rolling it out broadly.
What do I need to use Channel Agent?
Three things: a Microsoft Copilot subscription assigned to you, membership of the channel where the agent was created, and permission from your IT admin to use apps in Teams.
Can people without a Copilot licence use the Channel Agent?
They cannot interact with it, but they can still see the agent's responses, its generated content, and other people's interactions with it. So unlicensed channel members are spectators rather than participants.
What does Channel Agent know?
It answers using the channel's messages and meeting transcripts, and web search if your organization's IT admin allows it. Meeting transcripts are used as knowledge sources, which is what makes it useful on projects that were never written down.
Can Channel Agent work with Jira, Asana or GitHub?
Yes. Microsoft documents using Channel Agent to manage tasks in Jira, Asana and GitHub, alongside its built-in task creation and reminders.
Can I set up Channel Agent from my phone?
No. Agent creation, removal and configuration must be done from the desktop or web version of Teams. On mobile you can do things like report approval and feedback submission, provided you are on Teams 7.11.0 or higher on iOS, or 1416/1.0.0.2025100000 or higher on Android.
Can Channel Agent send email?
Yes. It can draft and send emails, which saves switching between Teams and Outlook for routine project communication.
